# Высота — платформа горных походов

Полноценный прототип Django для планирования треккинга в Казахстане: каталоги маршрутов, чек-лист экипировки, погода, помощник по подготовке, истории сообщества и профиль пользователя. Интерфейс по умолчанию на русском; Django поддерживает переключение между русским, казахским и английским.

## Требования

- Python 3.10 или новее
- pip
- Интернет нужен только для Google Fonts и удалённых фотографий; без API ключей приложение показывает демонстрационные ответы.

## Установка

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
python manage.py migrate
python manage.py seed_data
python manage.py runserver
```

Откройте http://127.0.0.1:8000/. Панель администратора доступна по `/admin/`; создайте администратора командой `python manage.py createsuperuser`.

Демонстрационный пользователь для входа: `trailguide` / `trailguide123`.

## Настройки API

Скопируйте `.env.example` в `.env` и задайте собственные значения. Не публикуйте файл `.env`.

- `SECRET_KEY` — секрет Django, необходим собственный при развёртывании.
- `DEBUG` — `True` для локальной разработки.
- `AI_API_KEY` — ключ Anthropic. Если он задан, помощник обращается к Anthropic Messages API; без ключа используется безопасная демонстрационная рекомендация.
- `WEATHER_API_KEY` — ключ OpenWeatherMap. При доступном ключе запрашивается прогноз; иначе отображаются демо-данные.

AI-помощник сохраняет до шести пар сообщений в текущей сессии и учитывает выбранные гору, сезон и длительность маршрута. В демо-режиме он накапливает упомянутое снаряжение и показывает ориентировочную готовность комплекта. Кнопка «Новый разговор» очищает контекст текущей сессии.

## Языки

Переключатель RU / KZ / EN находится в верхней панели. Активный язык хранит Django; русский — язык по умолчанию. Переведены подписи интерфейса, формы, категории и демо-содержимое маршрутов, снаряжения, историй и погоды. Тексты историй и комментариев, которые добавляют пользователи, остаются на языке автора.

Каталоги Django находятся в `locale/`. Готовые `.mo` файлы включены в проект. После правок существующих переводов пересоберите их командой `python tools/compile_catalogs.py`; `python tools/audit_template_i18n.py` проверяет, что буквальные строки шаблонов есть в обоих каталогах. Для автоматического извлечения новых строк через `makemessages` установите GNU gettext.

## Структура проекта

- `config/` — настройки, корневые URL и WSGI/ASGI
- `accounts/` — профили, регистрация и вход
- `mountains/` — каталоги маршрутов и команда `seed_data`
- `hikes/` — планы походов и экипировка
- `community/` — истории, комментарии и отметки «нравится»
- `weather/` — погодная панель и сервис прогноза
- `ai_assistant/` — интерфейс чата и сменяемый AI-сервис
- `templates/`, `static/`, `media/` — интерфейс и ресурсы

SQLite файл `db.sqlite3` создаётся автоматически миграциями. Фотографии в демо привязаны URL к удалённому источнику; собственные медиа можно положить в `media/`.

## Разработка

```powershell
python manage.py check
python manage.py makemigrations
python manage.py migrate
python manage.py seed_data
```

Для запуска приложения без установки зависимостей требуется Django, python-dotenv, requests и Pillow из `requirements.txt`.
